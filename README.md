# 🚀 PySpark & SQL Interview Practice

A comprehensive collection of SQL and PySpark interview questions solved using an E-commerce Orders dataset.

This repository is designed to help aspiring Data Engineers, Data Analysts, and Big Data Engineers practice real-world interview problems using SQL and Apache Spark (PySpark).

---

# 📌 Project Objective

The goal of this project is to strengthen SQL and PySpark skills by solving practical business problems commonly asked in technical interviews.

The notebook covers:

- SQL Basics
- Aggregations
- Filtering
- Sorting
- Group By
- Window Functions
- Date Functions
- String Functions
- Data Cleaning
- Business Analysis
- Revenue Analytics
